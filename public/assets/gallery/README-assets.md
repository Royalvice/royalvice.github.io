## Runtime Binding Strategy

At runtime, `src/gallery/PlayCanvasGallery.ts`:

- loads `models/wooden-gallery-cabinet-v6.glb` only;
- fails loudly if v6 is missing; there is no runtime fallback to v5, v4, v3, v2, v1, Cbox, or old room-box assets;
- binds `materials/walnut_cabinet_v6/*` and `cabinet_lightmap_v6.png` to the walnut outer frame, warm inner-wall, warm side-wall, right-side wall, inner-floor, and shadow-groove material slots;
- uses `walnut_cabinet_v6` as the production wood candidate; URL candidate switching is disabled in production for chroma stability;
- uses Studio Small 08 HDR to generate a PlayCanvas env atlas;
- places each source PNG/WEBP/JPG or DirectL MP4 frame as a neutral 16:9 hero media texture on the back wall, using `contain` letterboxing only;
- keeps title, venue, tier, Matrix glyphs, and UI copy outside the hero media texture, on the 3D plaque / frame / DOM hotspot layer;
- upgrades DirectL to a video texture when the browser reports playable video data;
- uses the trophy mesh contained in the v6 GLB via `slot-N.trophy-root`;
- keeps the physical glass pane and edge geometry in the GLB, with runtime materials tuned to be visible but not foggy or distorted;
- adds a localized display-case lighting rig per slot: warm rectangular key light, warm front fill, warm side-wall wash, hero-screen bounce light, and tier rim light via `slot-N.rim-light-anchor`;
- keeps the whole gallery inside one PlayCanvas canvas with one fixed perspective camera;
- exposes `window.__galleryDebug()` with `cabinetVersion: "v6"`, v6 source, lightmap readiness, anchor count, material bindings, generated hero-media readiness, hero color probes, DirectL video readiness, trophy mesh readiness, canvas count, WebGL context count, draw calls, triangles, FPS estimate, and lighting values.

## Regeneration

Run:

```bash
python3 tools/generate_walnut_cabinet_v6_textures.py
/Applications/Blender\ 4.2\ LTS.app/Contents/MacOS/Blender --background --python tools/generate_wooden_gallery_cabinet_v6.py
python3 tools/validate_gallery_cabinet_v6.py
```

The generated and validated outputs are:

```text
public/assets/gallery/models/wooden-gallery-cabinet-v6.glb
```

## Replacement Strategy

Future AI-generated or hand-authored assets should be placed in:

- `public/assets/gallery/models/`
- `public/assets/gallery/materials/`

The safest next step is to replace each generated trophy silhouette with a hand-authored or AI-generated glTF collectible while keeping the v6 walnut cabinet, warm wall material/lightmap contract, original-color hero media plane, plaque, top light, rim light, glass, and anchor contract stable.
