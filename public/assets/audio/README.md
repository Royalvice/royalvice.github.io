The dungeon music box and Horizon cloud controls share a single audio element, including playback position, pause state and seeking. Descending into Horizon (or loading it directly) attempts playback; a manual pause stays paused while scrolling upward into Voyage. Descending into Horizon again may resume. When browser autoplay rules prevent playback, the cloud presents a play button.
